# EstiloVivo — App Android nativa

App nativa (Kotlin + Jetpack Compose) de EstiloVivo. Usa el mismo servidor que la web
(`https://estilovivo.xyoncloud.win/api`). Web y servidor: https://github.com/mkandreum/estilovivo

- Estado, pendientes y cómo continuar: [`HANDOFF.md`](HANDOFF.md)
- Reglas de código y diseño: [`AGENTS.md`](AGENTS.md)
- Ficha de Google Play: [`PLAY_STORE.md`](PLAY_STORE.md)
- Compilar firmado con Android Studio: [`COMPILAR_FIRMADO.md`](COMPILAR_FIRMADO.md)

El contenedor Capacitor anterior (WebView) está en la rama `legacy-capacitor`.
